## タスク 2.1 細胞内ネット成長率と支配固有値

    d = ψ_max^in − k_A^in − k_exf − k_emerge = +1.2343 /h
    tr = ā + d = +0.9513 /h
    det = ā·d − k_emerge·k_invade = −0.349957 /h²
    Λ₊ = [tr + √(tr² − 4det)]/2 = +1.2347 /h   （倍加時間 ln2/Λ = 0.561 h）
    Λ₋ = −0.2834 /h

Λ₊ − d = +4.3e−4 /h。依頼書の期待値（d = +1.2343、Λ ≈ +1.234）と一致。
系の漸近的な運命が細胞内区画のみで決まっていることの確認が取れた。
Λ₊ > 0 は旧値より大きいので「細胞外の対策では根絶に届かない」という
既存の主張は向きが変わらず、むしろ強まる。

## タスク 2.2 Table 9.4.50（d = 0 にするための各レバー単独の必要値）

| レバー | 必要値 | 現実性 |
| --- | --- | --- |
| ψ_max^in | **≤ 0.0657 /h** まで下げる | IBC 帯の下限 0.69 /h を大きく下回る。到達不能 |
| k_exf | **≥ 1.2343 /h** | 到達不能 |
| k_emerge | **≥ 1.2993 /h** | IBC サイクル滞留時間と整合しない。到達不能 |
| k_A^in | **≥ 1.2350 /h** | 上限 1.70 /h の 72.6%。飽和域の極限のみ |

**依頼書との差異が 1 件。** 依頼書の期待値は k_A^in > 1.234 だが、
閉形式は **1.2350**。d = 0 の条件は k_A^in = ψ_max^in − k_exf − k_emerge
であり、k_A^in 自身の項は右辺に残らない。1.234 は d の値をそのまま
転記したもので、k_A^in = 0.0007 を二重に引いている。差は 7e−4 /h で
結論（到達不能）には影響しないが、表の数値は 1.2350 が正しい。
k_exf（1.2343）と k_emerge（1.2993）は依頼書と一致。

η と A_peak については、k_A^in の到達可能上限が ψ_max − ψ_min = 1.70 /h
（ρ^in = 1）なので必要値 1.2350 /h は全スパンの 72.6%。Hill 型
ψ = ψ_max − (ψ_max − ψ_min)·x^κ/(1 + x^κ)、x = η·A/MIC_R を仮定して逆解きすると

    x ≥ 1.3925  →  MIC_R^(0) = 163.2、A_peak = 300 のとき η ≥ 0.7575

**この Hill 型は sunrise_model.py 未確認の仮定**であり、公表前に実装と
照合すること。形が違えば η の必要値は動く。結論（飽和域の極限でしか
到達しない）は変わらない見込み。

## タスク 8 機械的効率軸 η_mech

    N_0 = η_mech · φ · m · P

φP を 1 個のパラメータとして保ったまま η_mech ∈ (0, 1] を前置きする。
m_∞、必要投与量 D、コース当たり総粒子数がすべて 1/η_mech でスケールする。
閉形式なので ODE の再実行は不要。

| η_mech | m_∞（粒子/CFU） | τ_P = 1 h の要求接着数（粒子/CFU） | 10–100 の範囲 |
| --- | --- | --- | --- |
| 1.0 | 411 | 86 | 収まる |
| 0.5 | 822 | 172 | **外れる** |
| 0.2 | 2055 | 430 | **外れる** |

m_∞ 列は Ver.22 の D = 3.0e11 粒子/回 に紐づいた値であり、
**タスク 1 で新 D が確定したら比例で引き直すこと**（D を 0.88 倍に
すれば m_∞ も 0.88 倍）。τ_P = 1 h 列は接着数の要求そのものなので
D には依存しない。

Ver.22 の「CPI の幾何から妥当な 10–100 粒子/菌 に収まるのは τ_P = 1 h の
場合だけ」という記述は η_mech = 1 の仮定に乗っている。η_mech ≤ 0.5 では
τ_P = 1 h でも範囲を外れ、**収まる条件がなくなる**。

## タスク 8.4 文書修正箇所

1. Parameters 表 φP の Source 欄 → 「CPI モジュール（幾何条件のみ。
   機械的穿孔効率と積載・放出効率は含まない上限）」
2. Table 9.4.22 →「幾何条件のみで算出した上限。範囲 10.7–34.9 は
   構造シナリオ（侵入角、残基数 125/133、離散化 0.4/0.5 nm）のみを張る」
   （「範囲の中央値」という記述を削除）
3. Assumption に追記 → 侵入角 ψ = 0° を基準に採る。ψ は粒子が菌表面に
   当たる角度で設計変数ではないが、φ を 0° → 30° で 1.76 倍
   （0.4366 → 0.7697）動かす。0° は保守側。
4. φ = 0.98 がコード中に残っていれば除去（本リポジトリには該当コードなし）。
5. φ と P を別々に持って掛けないこと。長さ依存の正の共分散により
   周辺値の積は真値より 4–18% 低い（ψ=0° で 16%: 0.4366 × 40.07 = 17.5
   に対し真値 20.29）。φP = 20.3 を 1 個のパラメータとして扱う。
